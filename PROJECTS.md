# Lahza (لحظة)

Bilingual (EN/AR) web app for personalised coffee gifts, event coffee
stations and corporate campaigns. Vite + React + TypeScript + Tailwind.

This repository previously hosted a multi-project workspace. The sibling
product lines now live in their own repositories:

- Wisal (وصال) family-messaging assistant → https://github.com/ahmadzayan-hub/wisal
- Beyond Style UAE orders console + landing → https://github.com/ahmadzayan-hub/masaar
- Annual Operational Plan 2026 → https://github.com/ahmadzayan-hub/annual-operation-plan-2026
